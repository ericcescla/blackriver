# Frontend

Sitio de Ruben Rodriguez y panel de administracion con React y Vite.

Instala las dependencias con npm.cmd install y ejecuta npm.cmd run dev.

El sitio usa el backend para recibir consultas y administrar servicios. Las instrucciones de configuracion, credenciales, despliegue y pruebas estan en el [README del proyecto](../README.md).
